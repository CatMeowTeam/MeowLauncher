## 🐾 Meow Launcher ver 2.0.0

Bản lớn đầu tiên! Meow giờ biết đếm FPS khi anh chơi game và tự báo khi có bản mới.

### 📥 Cài đặt
1. Tải **`MeowLauncherSetup-2.0.0.exe`** ở mục *Assets* bên dưới.
2. Windows hiện *“Windows đã bảo vệ máy tính của bạn”* thì bấm **Thông tin thêm → Vẫn chạy**.
3. Đang dùng bản 1.0.1 Beta thì cứ cài đè, danh sách app và cài đặt được giữ nguyên.

### ✨ Có gì mới
- 🎮 **Overlay FPS & nhiệt độ**: nhấn <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> để hiện FPS, CPU, GPU, RAM và nhiệt độ ở góc màn hình khi chơi game
- 🔔 **Tự cập nhật**: có bản mới là Meow báo, bấm một nút là cập nhật xong
- 🪶 **Nhẹ RAM hơn**: bớt một tiến trình nền, nằm yên dưới khay thì trả RAM thừa cho Windows
- 🌏 Cài đè bản mới không hỏi lại ngôn ngữ

### 💡 Mẹo cho overlay
- Chọn chế độ **Borderless** hoặc **Windowed Fullscreen** trong game để overlay hiện trên game.
- Đo FPS cần quyền Admin: bấm **Có** khi Windows hỏi.

### 💻 Yêu cầu
Windows 10 hoặc 11, 64-bit.
